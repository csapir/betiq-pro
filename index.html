🚀 פרסום BetIQ ב-GitHub Pages

מדריך שלב-אחר-שלב · 10 דקות · חינמי לגמרי
1. GitHub 2. העלאת קובץ 3. הפעלת Pages 4. URL חי! 5. API Keys
1
יצירת חשבון GitHub (אם אין לך)
GitHub הוא שירות חינמי לאחסון קוד. נשתמש בו כדי לאחסן ולהפיץ את האתר.
💡 אם יש לך כבר חשבון GitHub — דלג לשלב 2
  1. גש לאתר github.com
  2. לחץ Sign up ומלא אימייל, שם משתמש וסיסמה
  3. אמת את האימייל שלך
2
יצירת Repository חדש
Repository הוא כמו תיקייה לפרויקט שלך ב-GitHub.
  1. לחץ על + בפינה הימנית העליונה → New repository
  2. בשדה Repository name הכנס:
    betiq-pro
  3. בחר Public (חייב להיות Public לשימוש ב-Pages חינמי)
  4. סמן ✅ Add a README file
  5. לחץ Create repository
3
העלאת קובץ האתר
כעת נעלה את קובץ betiq-pro.html שהורדת.
  1. בתוך ה-Repository לחץ על Add file → Upload files
  2. גרור את הקובץ betiq-pro.html לאזור ה-Upload
  3. חשוב: שנה את שם הקובץ ל-
    index.html
  4. גלול למטה ולחץ Commit changes
💡 שם index.html חשוב — זה שם הקובץ הראשי שGitHub Pages טוען אוטומטית
4
הפעלת GitHub Pages
עכשיו נפעיל את שירות האחסון החינמי.
  1. לחץ על Settings (גלגל שיניים) בתפריט העליון של ה-Repository
  2. בתפריט הצדדי, לחץ Pages
  3. תחת Branch בחר main ולחץ Save
  4. המתן כ-2 דקות
🎉 לאחר כ-2 דקות, הדף יתרענן ותראה:
"Your site is live at https://USERNAME.github.io/betiq-pro"
💡 ה-URL שלך יהיה: https://[שם-משתמש-שלך].github.io/betiq-pro
5
עדכון האתר בעתיד
אם תרצה לעדכן את האתר (גרסה חדשה מהצ'אט):
  1. עבור ל-Repository שלך
  2. לחץ על הקובץ index.html
  3. לחץ על אייקון העיפרון ✏️ (Edit)
  4. מחק הכל והדבק את הקוד החדש
  5. לחץ Commit changes
  6. האתר יתעדכן אוטומטית תוך כדקה!

חינמי The Odds API
🔗 the-odds-api.com
הפלן החינמי מאפשר 500 קריאות API בחודש — מספיק לשימוש אישי יומי. מכסה יותר מ-40 ספורטים כולל פרמיר ליג, NBA, לה ליגה ועוד. מחיר ספקים: bet365, DraftKings, Unibet, Pinnacle ועוד.

  2. הירשם עם אימייל (חינמי, ללא כרטיס אשראי)
  3. לאחר אימות תקבל מפתח בצורה כזו:
    abc123def456ghi789jkl012mno345pq
  4. העתק את המפתח והכנס אותו ב-BetIQ בשלב ההגדרה
💡 טיפ חיסכון: האתר שומר את האודס במטמון (cache) — לא כל לחיצה על רענן צורכת קריאה

חינמי חלקי API-Football / API-Basketball

נתוני סטטיסטיקות, תוצאות, דירוגים, הרכבים ופציעות. הפלן החינמי: 100 קריאות ביום. מכסה יותר מ-900 ליגות כולל ליגת העל הישראלית, NBA, EuroLeague ועוד.
